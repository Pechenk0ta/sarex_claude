# Бот напоминаний о днях рождения (Google Таблица + Telegram)

Отдельное приложение, не связанное с Sarex. Данные лежат в Google Таблице: № | ФИО | Должность | День рождения | Компания.
Каждый день в 10:00 по Москве бот пишет вам в Telegram, у кого сегодня день рождения.
Людей можно добавлять, менять и удалять прямо в боте или в самой таблице.

## Установка (10 минут)

1. Откройте таблицу со списком (или создайте новую: sheets.new) → меню **Расширения → Apps Script**.
2. Удалите всё в файле `Code.gs` и вставьте содержимое [`dist/Code.gs`](dist/Code.gs) целиком. Сохраните (Ctrl+S).
3. Токен бота: впишите его в строку `const BOT_TOKEN_IN_CODE = '';` в начале файла
   или (надёжнее) в **Настройки проекта → Свойства скрипта** под именем `BOT_TOKEN`.
   В git токен не коммитится: для своего экземпляра есть `node tools/bundle.js ТОКЕН путь/Code.gs`.
4. **Настройки проекта** (шестерёнка) → «Часовой пояс» — `(GMT+03:00) Москва`.
5. В редакторе выберите функцию **`setup`** → **Выполнить**. Google попросит доступ: «Проверить разрешения» → ваш аккаунт → «Дополнительно» → «Перейти в проект» → «Разрешить».
6. Внизу в **Журнале выполнения** появится ссылка вида `https://t.me/ваш_бот?start=...`. Откройте её и нажмите «Старт». В течение минуты бот ответит «Готово, бот привязан к вам». Чужим людям бот не отвечает.
7. Проверка: функция `testReminderNow` → «Выполнить» — придёт сообщение.

## Таблица

Бот читает лист «Люди», а если такого нет — первый лист таблицы. Столбцы по порядку (названия в шапке могут быть любыми):

| № | ФИО | Должность | День рождения | Компания |
|---|---|---|---|---|
| 1 | Иванов Иван Иванович | Менеджер продукта | 12.03.1990 | Absolut |

- **№** можно не заполнять — бот проставит сам; по нему работают `/edit` и `/delete`.
- **Дата**: `ДД.ММ.ГГГГ` или `ДД.ММ` (без года бот не пишет возраст). Ячейки, которые Таблица сама превратила в даты, тоже читаются. Родившихся 29 февраля поздравляет 28-го в невисокосные годы.
- Список можно просто вставить в таблицу — бот подхватит его при следующем сообщении или в 10:00.

## Команды бота

| Команда | Что делает |
|---|---|
| `/today` | у кого сегодня |
| `/soon`, `/soon 60` | ближайшие 30 (60) дней |
| `/list` | все, по ближайшей дате, с номерами |
| `/add Иванов Иван Иванович; Менеджер продукта; 12.03.1990; Absolut` | добавить (дата может стоять в любом месте) |
| `/edit 5 дата 12.03.1991` (поля: фио, должность, дата, компания) | изменить |
| `/delete 5` | удалить (с подтверждением) |
| просто текст, например `иванов` или `менеджер` | найти; у карточки кнопки «Изменить» и «Удалить» |

Бот проверяет новые сообщения раз в минуту, поэтому отвечает с задержкой до минуты.

## Как устроено

- `src/` — исходники: `Config.js` (настройки: час напоминания, название листа), `Dates.js`, `Sheet.js`, `Telegram.js`, `Bot.js`, `Main.js`.
- `dist/Code.gs` — те же файлы одним файлом для вставки в редактор. После правки `src/`: `node tools/bundle.js`.
- Ваш chat_id хранится в «Свойствах скрипта»; токен — там же или в `BOT_TOKEN_IN_CODE` вашего экземпляра (в git пусто).
- Сообщения забираются через `getUpdates` триггером раз в минуту (вебхук на Apps Script Telegram считает ошибкой из-за перенаправления 302). Тот же триггер в 10:00 отправляет напоминание — ровно одно в день.
- Тесты без Google и Telegram: `node tests/run.js`.
