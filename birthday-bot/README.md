# Бот напоминаний о днях рождения (Google Таблица + Telegram)

Отдельное приложение, не связанное с Sarex. Данные лежат в Google Таблице на листе «Люди».
Каждый день в 10:00 по Москве бот пишет вам в Telegram, у кого сегодня день рождения.
Людей можно добавлять, менять и удалять прямо в боте или в самой таблице.

## Установка (10 минут)

1. Создайте Google Таблицу (sheets.new) → меню **Расширения → Apps Script**.
2. Удалите всё в файле `Code.gs` и вставьте содержимое [`dist/Code.gs`](dist/Code.gs) целиком. Сохраните (Ctrl+S).
3. Слева **Настройки проекта** (шестерёнка):
   - «Часовой пояс» — `(GMT+03:00) Москва`;
   - внизу **Свойства скрипта → Добавить свойство**: имя `BOT_TOKEN`, значение — токен бота от @BotFather. Сохраните.
4. Вернитесь в редактор, вверху выберите функцию **`setup`** → **Выполнить**. Google попросит доступ: «Проверить разрешения» → ваш аккаунт → «Дополнительно» → «Перейти в проект» → «Разрешить».
5. Внизу в **Журнале выполнения** появится ссылка вида `https://t.me/ваш_бот?start=...`. Откройте её и нажмите «Старт». В течение минуты бот ответит «Готово, бот привязан к вам». Чужим людям бот не отвечает.
6. Проверка: выберите функцию `testReminderNow` → «Выполнить» — придёт тестовое сообщение.

## Таблица

Лист «Люди» создаётся сам. Столбцы:

| ID | Имя | Дата рождения | Кто | Заметка |
|---|---|---|---|---|
| 1 | Иван Петров | 12.03.1990 | коллега | любит кофе |
| 2 | Мама | 05.11 | семья | |

- **ID** можно не заполнять — бот проставит сам.
- **Дата**: `ДД.ММ.ГГГГ` или `ДД.ММ` (без года бот не пишет возраст). Родившихся 29 февраля поздравляет 28-го в невисокосные годы.
- Список можно просто вставить в таблицу — бот подхватит его при следующем сообщении или в 10:00.

## Команды бота

| Команда | Что делает |
|---|---|
| `/today` | у кого сегодня |
| `/soon`, `/soon 60` | ближайшие 30 (60) дней |
| `/list` | все, по ближайшей дате, с номерами |
| `/add Иван Петров; 12.03.1990; коллега; заметка` | добавить |
| `/edit 5 дата 12.03.1991` (поля: имя, дата, кто, заметка) | изменить |
| `/delete 5` | удалить (с подтверждением) |
| просто текст, например `иван` | найти; у карточки кнопки «Изменить» и «Удалить» |

Бот проверяет новые сообщения раз в минуту, поэтому отвечает с задержкой до минуты.

## Как устроено

- `src/` — исходники: `Config.js` (настройки: час напоминания, название листа), `Dates.js`, `Sheet.js`, `Telegram.js`, `Bot.js`, `Main.js`.
- `dist/Code.gs` — те же файлы одним файлом для вставки в редактор. После правки `src/`: `node tools/bundle.js`.
- Токен и ваш chat_id хранятся только в «Свойствах скрипта», в коде их нет.
- Сообщения забираются через `getUpdates` триггером раз в минуту (вебхук на Apps Script Telegram считает ошибкой из-за перенаправления 302). Тот же триггер в 10:00 отправляет напоминание — ровно одно в день.
- Тесты без Google и Telegram: `node tests/run.js`.
